# Púa

Afinador de guitarra, bajo y ukelele, y cancionero con tabs, autoscroll y práctica de melodía con la voz.

Es una app web instalable (PWA): ábrela en Safari del iPhone y elige Compartir → «Agregar a pantalla de inicio».
Las canciones se guardan solo en el teléfono; usa «Exportar copia» para respaldarlas.
